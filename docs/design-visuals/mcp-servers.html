MCP Server Properties

● Status — connected (green) / disconnected (red) / error (yellow)
Scope — user (global) / project / local (private)
Type — stdio / sse / http
Command — the executable or URL
Args — command arguments
Tools — list of tools the server provides

Actions

+ Add Server — form to configure new MCP (wraps claude mcp add)
Edit — modify command, args, env vars
Remove — delete with confirmation (wraps claude mcp remove)
Refresh Status — re-run health checks
Marketplace — browse and install from available external plugins with MCP configs
