Key Corrections from Verifiers

  1. MCP configs live in ~/.claude.json, NOT settings.json. "Local" scope = per-project data in .claude.json under projects["path"].mcpServers.
  2. sessions-index.json is stale — 17/20 JSONL files missing from it. Must enumerate .jsonl files directly.
  3. PID files are deleted on session end — only active sessions have files in sessions/.
  4. Process is node.exe, not claude.exe. Must check CommandLine for claude-code/cli.js.
  5. PTY not in tauri-plugin-shell — need custom Rust plugin with portable-pty crate or ConPTY.
  6. Session names (slug) not indexed — appear deep in JSONL, only in 9/20 sessions.
  7. Plugin version can be 12-char git SHA, not always semver (e.g. a5bcdd7e58cd).
  8. Dual-write risk — must verify no PID file references a sessionId before resuming.
  9. Permission mode has 6 choices: acceptEdits, auto, bypassPermissions, default, dontAsk, plan.
  10. document-skills has NO plugin.json — metadata comes from marketplace registry only.

State Detection Visual Actions
ALIVE PID file exists + node.exe with cli.js Green dot (pulse) View Live, Resume in Terminal, Open CWD, Tag/Rename, Stop

ORPHANED Index entry but no JSONL Yellow dot Resume, Delete from list
